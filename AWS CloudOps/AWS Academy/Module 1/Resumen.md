#AWS #Cloud #Contexto #IAM

![[Resumen-1780958124257.webp|522]]

Este módulo de AWS se centra en las **operaciones de sistemas en la nube**, la **gestión de identidades y accesos (IAM)** y el uso de la **interfaz de línea de comandos (AWS CLI)**. A través de demostraciones grabadas y un laboratorio práctico, aprenderás a crear usuarios y grupos IAM, además de instalar y utilizar el AWS CLI para administrar servicios y recursos en la nube. También incluye una verificación de conocimiento para reforzar lo aprendido.

Al finalizar el módulo, serás capaz de **describir y explicar** cómo funcionan las operaciones automatizadas en la nube, los **servicios principales de AWS** (como red, cómputo y acceso), y los **criterios para seleccionar regiones y ubicaciones de borde**. Además, comprenderás cómo **IAM protege los recursos de tu cuenta** y podrás identificar las **características clave del AWS CLI** para gestionar tu infraestructura de manera eficiente.
