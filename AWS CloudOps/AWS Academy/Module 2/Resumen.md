En este módulo se van a ver las diferentes herramientas de automatización para el manejo de sistemas en AWS. Comenzaremos con AWS Systems Manager y algunos servicios centrales que se usan para administrar y automatizar tareas administrativas. Además, veremos cómo crear un sitio estático con S3 y conoceremos las características clave de AWS Systems Manager.

Al finalizar este módulo, debes ser capaz de describir el propósito y la función de AWS Systems Manager, así como sus características relacionadas. También deberás poder explicar el propósito y la función de las herramientas de AWS para PowerShell.

Asimismo, deberás poder identificar las herramientas utilizadas para la automatización, como los SDKs, AWS CloudFormation y AWS OpsWorks.
