
# 🧠 Mi Cerebro Digital: Apuntes Universitarios & Cloud/DevOps ☁️

¡Hola! 👋 Bienvenido(a) a mi repositorio. Este espacio actúa como el respaldo de mi bóveda de **Obsidian**, donde documento todo mi proceso de aprendizaje, estructurando conocimiento tanto académico como autodidacta.

## 🎯 Propósito del Repositorio

Aquí alojo mis notas, esquemas y reflexiones divididas en dos grandes mundos:

1. **🎓 Carrera Universitaria:** Apuntes de clases, proyectos y fundamentos teóricos.
    
2. **🚀 Aprendizaje Individual (Cloud & DevOps):** Experimentación práctica, arquitecturas, automatización y despliegue.
    

## 🗂️ Estructura de la Bóveda

El repositorio está organizado en las siguientes categorías principales para facilitar la navegación:

### 🏫 Universidad

- 📚 **Asignaturas:** Resúmenes, fórmulas y preparaciones para exámenes.
    
- 📝 **Proyectos:** Documentación de trabajos académicos y entregables.
    
- 🔬 **Investigación:** Notas sobre metodologías y teoría general.
    

### ☁️ Cloud Computing & DevOps

- 🌩️ **Amazon Web Services (AWS):** Notas prácticas sobre servicios core, configuración de IAM, EC2, API Gateway y funciones Lambda.
    
- 🐍 **Automatización & Scripting:** Desarrollo de scripts y automatización de procesos utilizando Python.
    
- 📡 **Arquitecturas IoT:** Documentación sobre ingesta de datos, telemetría y procesamiento de información de sensores.
    
- ⚙️ **Prácticas DevOps:** Integración continua, control de versiones y administración de infraestructura.
