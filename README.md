Bienvenido al repositorio que sirve como respaldo centralizado para mi bóveda de Obsidian. En este espacio organizo y documento de manera sistemática mi progreso académico universitario y mi ruta de aprendizaje autónomo en las áreas de Cloud Computing y DevOps.

## Propósito del Repositorio

El objetivo de este repositorio es mantener un control de versiones de mis notas estructuradas, permitiendo conectar conceptos teóricos de la universidad con implementaciones prácticas de infraestructura en la nube, automatización y despliegue continuo.

El contenido se divide en dos secciones principales:
1. **Carrera Universitaria:** Fundamentos teóricos, notas de asignaturas y proyectos académicos.
2. **Aprendizaje Individual:** Guías prácticas, configuraciones de arquitectura, automatización de tareas y pipelines de infraestructura.

---

## Estructura de la Bóveda

El repositorio mantiene la siguiente jerarquía de carpetas principales para facilitar la navegación y la interconexión de conceptos:

### Universidad
* **Asignaturas:** Resúmenes, fórmulas, metodologías y material de estudio para exámenes.
* **Proyectos:** Documentación de trabajos grupales, individuales y entregables académicos.
* **Investigación:** Notas sobre desarrollo teórico, estado del arte y documentación científica.

### Cloud Computing y DevOps
* **Proveedores de Nube (AWS, GCP, Azure):** Notas sobre servicios core, gestión de identidades y accesos (IAM), recursos de cómputo, redes virtuales, bases de datos y arquitecturas serverless.
* **Automatización y Scripting:** Desarrollo de scripts y automatización de procesos de backend utilizando Python.
* **Contenedores y Orquestación (Docker, Kubernetes):** Creación y optimización de imágenes, gestión de volúmenes, redes y despliegues en entornos orquestados.
* **Infraestructura como Código (Terraform):** Definición, modularización, manejo de estados y aprovisionamiento de recursos cloud de forma declarativa.
* **Integración y Despliegue Continuo (GitHub Actions):** Configuración de flujos de trabajo automatizados para pruebas unitarias, construcción de artefactos y pipelines de despliegue.

---

## Herramientas de mi Flujo de Trabajo

* **Obsidian:** Entorno principal para la toma de notas en formato Markdown puro mediante el uso de enlaces bidireccionales y organización basada en grafos.
* **Git y GitHub:** Control de versiones distribuidas y respaldo remoto seguro de toda la bóveda de conocimiento.

## Estado del Jardín Digital

Este repositorio adopta la metodología de un Jardín Digital. Las notas están en constante evolución, crecimiento y transición. Es posible encontrar documentos iniciales que funcionan como anotaciones rápidas o ideas sueltas (semillas), así como también guías exhaustivas técnicamente maduras y completamente estructuradas (árboles).
