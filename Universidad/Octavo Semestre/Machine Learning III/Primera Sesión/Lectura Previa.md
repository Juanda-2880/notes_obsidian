Todo proceso de decisiones que se realice debe de tener un proceso de imaginar o visualizar el futuro para llegar a este. El enfoque en este caso no deben de ser intuiciones o preconcepciones del analista que terminan siendo Data Driven.

#### Diferencia entre Planear y Pronosticar

Muchas veces se piensa que estos conceptos son iguales, pero estos están muy relacionados entre si, Planificación termina siendo la respuesta a como, cuando y que hacer para que el futuro se comporte como se desea.

*"Planeación es el proceso de pensar en el curso de acción futuro que se requiere para lograr un objetivo específico"*

Normalmente la planeación implica estos pasos:
- Identificar el Objetivo
- Seleccionar Estrategias para alcanzar el Objetivo
- Identificar los Recursos Necesarios
- Crear una línea de tiempo
- Determina el método de evaluación y seguimiento
- Identificar tareas y responsables 
- Implementar y supervisar todos los pasos cuidadosamente 


El proceso de realizar pronósticos emplea datos pasados y presentes y el análisis de patrones, tendencias históricas para realizar predicciones del comportamiento futuro  

Normalmente pronosticas implica estos pasos:
- Entender el problema e identificar la Variable a Pronosticar
- Crear una Base de Datos con la información Histórica
- Determinar las características mas relevantes del comportamiento histórico 
- Escoger el "mejor" modelo entre las diferentes posibles aproximaciones, para explicar el comportamiento de la variable a pronosticar en la muestra de evaluación
- Realizar un monitoreo continuo del comportamiento de los pronósticos 

### Tipos de Pronósticos

Se tienen dos formas de determinar el comportamiento futuro de la o las variables de interés que serían los Discrecionales y los Cuantitativos

- Discrecionales: Estos dependen del juicio de las personas o grupos y no están sometidos a una regla o normal
- Cuantitativos
	- Los que usan métodos estadísticos tienen la opción de los Univariados que usan técnicas de series de tiempo cuyo objetivo es emplear la información contenida en el comportamiento histórico de la variable para pronosticar su comportamiento futuro.
	- Los Multivariables emplean información de una o más variables diferentes a la variables de interés para pronosticar el comportamiento futuro (Un ejemplo es la regresión Múltiple)

Es importante saber que existen 4ro tipos de Analítica
- Descriptiva: Responde a la pregunta ¿Qué está pasando en mi negocio? Para este tipo se usa las bases de datos de la compañía, o las disponibles públicamente y emplea la estadística para explorar los datos (Estas pueden ser un poco más sofisticadas que calcular una media simple o una desviación estándar hablando de las series de tiempo)
- Diagnóstica: Este responde al ¿Porqué esta pasando lo que está pasando en el negocio? Este tipo de análisis tiene la capacidad de encontrar las causas de los problemas
- Predictiva: Este busca responder ¿Qué es posible que ocurra? Para esto se apoya en datos históricos, es decir, con los datos que ya se tienen se predicen los comportamientos que aún no se conocen
- Prescriptiva: Este busca responder ¿Qué necesito hacer? Este tipo de analítica hace énfasis en el uso de técnicas de optimización para identificar cual es la mejor alternativa para minimizar o maximizar algún objetivo

Cada uno de estos responden diferentes preguntas de negocio y no necesariamente es una mejor que otra.
