### Superficie de Ataque

Attack Surface es el conjunto total de puntos o interfaces de entrada por donde los atacantes pueden intentar comprometer un sistema, red o dispositivos, unas interfaces pueden ser:

1. Interfaces físicas: Puertas de acceso, enchufes, dispositivos de red, etc.
2. Interfaces digitales: Redes Wi-Fi públicas, servidores web, aplicaciones de red social, sistemas de correo electrónico, etc.
3. Software y sistemas operativos
4. Aplicaciones y servicios desplegados en la red
5. Dispositivos inteligentes y Internet de las cosas (IoT)
6. Interfaces de usuario y software cliente
