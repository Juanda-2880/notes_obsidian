#Ciberseguridad #Universidad #Quiz


- **¿Qué es la identificación? (Identification)** Es un mecanismo mediante el cual las entidades no verificadas que buscan acceder a un recurso proporcionan una etiqueta por la cual son conocidas por el sistema.
    
- **¿Qué es la autenticación? (Authentication)** Es el proceso de validar la identidad supuesta de un solicitante (supplicant). Este paso verifica y confirma de manera irrefutable la identidad de un usuario, dispositivo o proceso antes de permitirle interactuar con un sistema.
    
- **¿Qué es la autorización? (Authorization)** La autorización es la vinculación de una entidad autenticada con una lista de activos de información y sus niveles de acceso correspondientes. Determina exactamente qué tiene permitido hacer un usuario (leer, escribir, modificar, borrar) basándose en roles corporativos y políticas de seguridad.
    
- **¿Qué es la trazabilidad / rendición de cuentas? (Accountability)** También conocida como auditabilidad, es el mecanismo que asegura que todas las acciones en un sistema (ya sean autorizadas o no autorizadas) puedan ser atribuidas a una identidad autenticada específica. Esto generalmente se logra mediante el mantenimiento de registros del sistema (logs) y diarios de bases de datos.
    
- **¿Qué se puede utilizar como un ID de usuario?** Un ID de usuario es una etiqueta que debe estar asignada a una y solo una entidad dentro del dominio de seguridad. Las organizaciones pueden usar un nombre completo, la inicial del primer nombre y el apellido, o identificadores compuestos creados al concatenar códigos de departamento, números aleatorios o caracteres especiales.
    
- **¿Qué es un solicitante? (Supplicant)** Un solicitante es una entidad no verificada (como un usuario o un sistema) que busca acceder a un recurso.
    
- **¿Qué es un factor de autenticación?** Es un mecanismo específico utilizado para validar la identidad de un solicitante durante el proceso de autenticación.
    
- **¿Cuáles son los tres tipos de factores de autenticación?**
    
    1. **Algo que el solicitante sabe (Conocimiento):** Información que solo el usuario debería saber, como una contraseña, frase de contraseña (passphrase) o PIN.
        
    2. **Algo que el solicitante tiene (Posesión):** Un elemento físico o digital que el usuario posee, como una tarjeta inteligente, un token síncrono/asíncrono o la recepción de un SMS.
        
    3. **Algo que el solicitante es (Inherencia):** Características físicas o de comportamiento individuales, a menudo medidas a través de biometría como huellas dactilares, escaneos de retina e iris, o la topografía de la mano.
